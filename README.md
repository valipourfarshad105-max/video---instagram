# پکیج ۸۰ ویدیوی کاور افراز پلیمر

## معرفی پروژه

- **تعداد ویدیوها:** ۸۰
- **تعداد مدل‌های کاور:** ۵
- **تعداد محصولات:** ۱۶
- **مدت هر ویدیو:** ۱۰ ثانیه
- **فرمت:** عمودی
- **حرکت تصویر:** حرکت نرم زوم و پن روی تصویر کاور متناظر
- **منبع موسیقی:** مخزن `music-10-sanie` ارائه‌شده توسط کاربر

تمام ۸۰ تصویر کاور (۵ مدل × ۱۶ محصول) به ویدیوهای عمودی ۱۰ ثانیه‌ای تبدیل شده‌اند. هر ویدیو فقط از تصویر کاور متناظر خود با حرکت نرم زوم و پن استفاده می‌کند.

۵۲ ترک موسیقی به ترتیب استفاده شده‌اند و برای ویدیوهای ۵۳ تا ۸۰، ترتیب ترک‌ها از ابتدا تکرار شده است.
